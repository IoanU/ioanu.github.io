# Ioan Ursescu — Portfolio

The homepage is a static project index. Its illustrations are drawn locally in the browser. The bracket stamp on the ASCII Face Lab row reveals the original interactive ASCII portrait at `/portrait/`, with its original renderer, model data, and attribution.

To add a project, copy a row in the project list in `index.html` and update its title, description, and destination. Remove the copied `data-study` to use the default numbered poster; add `data-medium` if that poster needs a caption. The index numbers and paginates the rows automatically, six per page.

The site is published by GitHub Pages from the root of `main`.
